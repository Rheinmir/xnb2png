# Tech Stack

## Core Engine
- **Framework**: React 18
- **Build Tool**: Vite 5
- **Language**: JavaScript (ESModules)

## Libraries
- **Styling**: TailwindCSS (with PostCSS & Autoprefixer)
- **Icons**: lucide-react
- **File Handling**: react-dropzone
- **Utilities**: 
  - `folderNormalizer.js`: Custom logic for directory standardization.
  - `xnb.js`: Custom logic for XNB binary format handling.

## Infrastructure
- **Containerization**: Docker
- **CI/CD**: Jenkins
- **Web Server**: Nginx (inside Docker)
- **Registry**: GitHub Container Registry (ghcr.io)
